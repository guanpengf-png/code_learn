# 指针速查

配合 `point` 里 01–25 的源文件。字节数是这台 64 位机器上的：`int` 4，指针 8，普通 `struct Student` 12。第 17、25 章多了一个指针成员，结构体是 24。

细的走查在 `指针章节笔记.md`。这里只留要背的规律和每条写法的结果。

## 规律

**1. 从名字往外读**

名字右边紧挨 `()` 就是函数，被 `(* )` 包住就是指针，右边紧挨 `[]` 就是数组。`const` 修饰它左边那一个；左边什么都没有，就修饰右边紧挨着的那一个。

| 声明 | 它是什么 |
|---|---|
| `int *p` | 指针，指向 `int`。能改指向，能写 `*p` |
| `const int *cp` | `const` 锁 `int`。能改指向，`*cp` 只读 |
| `int *const fp` | `const` 锁指针格子。不能改指向，能写 `*fp` |
| `const int *const` | 两边都锁，只能读 |
| `int *f(int)` | 指针函数：函数，返回 `int *` |
| `int (*f)(int)` | 函数指针：指针，指向返回 `int` 的函数 |
| `int (*a[2])(int)` | 函数指针数组 |
| `int *(*f)(int)` | 函数指针，指向的函数返回 `int *` |
| `int (*f(int))[3]` | 指针函数，返回「指向 3 个 `int` 的数组」的指针 |

**2. `+ 1` 跨过的是「它指着的那一个」**

`p + 1` 的步长是 `sizeof(*p)`，不是 `sizeof(p)`。指针自己永远是 8 字节。

| 类型 | `+ 1` |
|---|---|
| `int *`、`char` 除外的单个对象指针 | `sizeof` 那个对象 |
| `char *` | 1 字节 |
| `int **`、`int (*)(int, int)` 这种指针的指针 | 8 字节，跨过一个指针格子 |
| `int (*)[5]` | 20 字节，一整段 |
| `int (*)[3]` | 12 字节，一整行 |
| `int (*)[2][3]` | 24 字节，整张表 |
| `struct Student *` | 12 字节，一个学生 |
| `struct Student (*)[3]` | 36 字节，一整组 |

`p + i` 只算出新地址，`p` 自己不动。要挪 `p`，写成 `p = p + 1` 或 `p++`。

**3. 下标就是解引用**

`a[b]`、`b[a]`、`*(a + b)`、`*(b + a)` 是同一格。`&` 和紧挨着的 `*` 抵消。`at = nums + 2` 时，`at[-1]` 是前一格，`at[1]` 是后一格。

**4. 数组名什么时候退化**

用在表达式里，数组名变成「指向首元素的指针」。`sizeof 数组名` 和 `&数组名` 不退化。

- `sizeof nums`（5 个 `int`）是 20，`sizeof &nums[0]` 是 8。
- `&nums` 和 `&nums[0]` 起始字节相同，类型不同：`int (*)[5]` 和 `int *`。
- 形参写成 `int a[5]`、`int a[]`、`int *a`，函数里都是 `int *`，`sizeof` 是 8。要保住整段，形参写成 `int (*block)[5]`，实参传 `&nums`，`sizeof *block` 仍是 20。

**5. 函数里改的是哪一格**

形参是副本，函数结束就没了。副本里如果装的是地址，顺着 `*` 能写到外面。

| 写法 | 改到哪里 |
|---|---|
| `x = 100` | 只改形参里的数 |
| `p = NULL`、`p = p + 1` | 只改形参里的指针 |
| `*p = ...` | 改调用者那个对象 |
| `*pp = ...` | 改调用者那个指针变量。实参要传 `&cursor` |
| `**pp = ...` | 改那个指针最终指着的 `int` |
| 结构体按值传递，但 `*s.score = ...` | 结构体是副本；`score` 里的地址仍指向原来的 `int` |

`*p++` 是 `*(p++)`：先读，再让 `p` 前进。`*pp + 1` 是 `(*pp) + 1`：先取出指针，再按它指着的类型跨一步。

**6. 几层 `*` 就走几格**

`int **pp` 指向一个 `int *`。`*pp` 是那个指针格子，`**pp` 才是 `int`。`slot` 是 `int *[3]` 时，`**(slot + i)` 走到 `b`；`*(*slot + i)` 已经先落到 `&a`，再按 `int` 从 `a` 旁边挪，到不了 `b`。

**7. 函数名会退化成函数指针**

`add` 和 `&add` 是同一个地址。`op(20, 3)`、`(*op)(20, 3)`、`(**op)(20, 3)` 都能调用。空的函数指针要先判断，再调用。

指针函数交回的是地址，后面还要 `*`、`[]`，或者再写一对 `()` 才真正用它。`choose(0)(20, 3)`：第一对 `()` 调用 `choose` 得到函数指针，第二对才调用 `add`。

局部变量的地址不能返回。`static` 变量在函数返回后还在，返回它的地址是安全的。

## 01 一级指针

`*p` 顺着地址走进对象。`p` 里放的是地址。

| 写法 | 结果 | 记 |
|---|---|---|
| `*p`，然后 `*p = 20` | 先 10，`a` 变成 20 | 读和写都走 `p` 里的地址 |
| `p == &a`、`&*p == p` | 相同 | `*` 再 `&` 回到这格的地址 |
| `*&a` | 20 | `&` 再 `*` 回到对象 |
| `q = p; *q = 30` | `*p` 也是 30 | 两个指针指着同一格 |
| `const int *cp = &a` 再 `cp = &b` | 30，然后 50 | 能换指向，只读 |
| `*fp = 40`，`fp` 是 `int *const` | `a` 变成 40，`fp` 仍是 `&a` | 能写对象，不能换指向 |
| `*both` | 50 | 两边都锁，一直指着 `b` |
| `*(int *)vp` | 40 | `void *` 要先转回 `int *` |
| `*(*&p)` 也就是 `*&p` 再 `*` | 40 | `&p` 是指针自己的地址，类型 `int **` |

## 02 传值

传进去的是副本。`main` 里的原件不动。

| 写法 | `main` 里 |
|---|---|
| `set_copy(a)`，函数里 `x = 100` | `a` 仍是 10 |
| `set_copy(*cursor)` | 传的是数 10，不是指针。`*cursor` 仍是 10 |
| `set_copy(nums[2])` | `nums[2]` 仍是 30 |
| `drop(cursor)` 里 `p = NULL` | 函数里「是」，`main` 里「否」，`*cursor` 仍是 10 |
| `step(cursor)` 里 `p = p + 1` | 函数里「动了」，`*cursor` 仍是 10 |

## 03 传地址

形参拿到地址的副本，`*p` 写的是原来那一格。

| 写法 | 结果 |
|---|---|
| `set_target(&a)` | `a` 从 10 变成 100 |
| `add_one(p)`，`p` 已经指向 `a` | `a` 变成 101 |
| `set_target(&nums[2])` | 只有第 2 格变成 100，`nums[0]` 仍是 10 |
| `swap(&a, &b)` | 101 和 20 对调，打出 `20 101` |
| `fill(nums, 5, 1)` | `1 2 3 4 5` |
| `fill(&nums[0], 3, 7)` | 只写前 3 格：`7 8 9 4 5` |

## 04 指针参数也是副本

`nums` 开始是 `{10, 20, 30}`，`cursor` 指向第 0 格。

| 写法 | 结果 | 记 |
|---|---|---|
| `drop(cursor)` | `*cursor` 仍是 10 | 形参变成 `NULL` |
| `step(cursor)` | `*cursor` 仍是 10 | 形参 `+ 1`。`income` 也随函数结束消失 |
| `write_star(cursor)` | `nums[0]` 和 `*cursor` 都是 100 | `*p` 写对象，指向不变 |
| `move_caller(&cursor)` | `*cursor` 变成 20 | `*pp = (*pp) + 1`，改的是 `cursor` 这格 |
| `write_through(&cursor)` | `nums[1]` 变成 7 | `**pp` 写那个 `int` |

`pp` 是 `int **`：`*pp` 是 `cursor`，`**pp` 是它指着的数。

## 05 下标

`nums` 是 `{10, 20, 30, 40, 50}`，`i` 是 2。下面都是 30：

`nums[i]`、`i[nums]`、`*(nums + i)`、`*(i + nums)`、`p[i]`、`i[p]`、`*(p + i)`、`*(i + p)`、`(&nums[0])[i]`、`*(&nums[i])`。

`at = nums + 2` 时：`at[0]` 是 30，`at[-1]` 是 20，`at[1]` 是 40。`p[k]` 走完是 `10 20 30 40 50`。

## 06 元素地址

第 2 格的这些地址相同，读出来是 30：

`nums + i`、`&nums[i]`、`&i[nums]`、`&*(nums + i)`、`&p[i]`、`p + i`、`&nums[0] + i`。`&nums[0]` 和表达式里的 `nums` 相同。

`&nums` 和 `&nums[0]` 起始字节相同。`sizeof nums` 是 20，两个地址的 `sizeof` 都是 8。

## 07 普通指针走一步

`p` 是 `int *`，一步 4 字节。`end = nums + 5` 在最后一格的后面，可以形成这个地址，不要 `*end`。

| 写法 | 结果 |
|---|---|
| `*p`、`*(p + 1)`、`*(p + 4)` | 10、20、50。`p` 没动 |
| `p + 1 == &nums[1]` | 相同 |
| `*(p + i)` 循环 | `10 20 30 40 50` |
| `saved = p; p = p + 1` | 打出 `20 10` |
| `*walk++`，`walk < end` | `10 20 30 40 50`。`*walk++` 是先读再前进 |
| `end - nums` | 5，元素个数 |
| 从 `end` 先 `--` 再读 | `50 40 30 20 10` |

## 08 数组指针走一步

`table` 两行各 5 个 `int`。`block` 是 `int (*)[5]`，一步 20 字节。`one` 是 `int *`，一步 4 字节。整张表 40 字节。

| 写法 | 结果 |
|---|---|
| `(*block)[0]` | 10 |
| `(*(block + 1))[0]`、`[2]` | 60、80 |
| `block[1][1]` | 70。`block[1]` 就是 `*(block + 1)` |
| 两行分别走 | `10 20 30 40 50` 和 `60 70 80 90 100` |
| `*(one + 1)`、`*(one + 4)` | 20、50。还在第 0 行 |
| `block = block + 1` | `(*block)[0]` 变成 60 |

## 09 指针数组

`slot` 是 `{&a, &b, &c}`，数是 10、20、30。先走到第 `i` 个指针，再 `*` 一次。`i = 1` 时是 20。

这 8 种都打出 `10 20 30`：`*slot[i]`、`*i[slot]`、`**(slot + i)`、`**(&slot[i])`、`slot[i][0]`、`**(p + i)`、`*(*p++)`、`*(*block)[i]`。

`p` 是 `int **`，一步 8 字节。`block` 是 `int *(*)[3]`，一步 24 字节。`*p++` 只解开一层，得到的还是指针，所以要 `*(*p++)`。`*(*slot + i)` 从 `&a` 按 `int` 挪，不是这 8 种。

## 10 数组指针

`block` 是 `int (*)[5] = &nums`，`p` 是 `int * = nums`。`sizeof nums` 和 `sizeof *block` 是 20，`sizeof p` 是 8。

下面都是 30：`(*block)[2]`、`block[0][2]`、`*(*block + 2)`、`*(block[0] + 2)`、`2[*block]`、`2[block[0]]`、`*&(*block)[2]`、`p[2]`、`at2(&nums)`。整段是 `10 20 30 40 50`。

## 11 二维数组的行

`grid` 是 `{{1,2,3},{4,5,6}}`。一个 `int` 4 字节，一行 12，整张表 24。12 种走法都打出两行。

| 写法 | 一步在跨什么 |
|---|---|
| `grid[r][c]`、`c[r[grid]]` | 下标。对调后仍是同一格 |
| `*(*(grid + r) + c)`、`(*(grid + r))[c]` | `grid + r` 的类型是 `int (*)[3]`，先跨行 |
| `*(grid[r] + c)`、`*(&grid[r][0] + c)` | 行退化成 `int *`，再按列跨 |
| `*(*grid + r * 3 + c)` | `*grid` 落到第 0 行再退化，一步 4 字节 |
| `row[r][c]` | `row` 是 `int (*)[3]` 的副本，自己不动 |
| `(*row)[c]` 然后 `row++` | `row++` 跨 12 字节 |
| `*(flat + r * 3 + c)`、`*flat++` | `flat` 是 `int *`。`*flat++` 打成 `1 2 3 4 5 6` |
| `(*block)[r][c]` | `block` 是 `int (*)[2][3]`，一步 24 字节 |

## 12 指针函数

函数返回地址。`nums[3]` 开始是 40。

| 写法 | 结果 | 记 |
|---|---|---|
| `*element(nums, 3)`、存进 `found` | 40 | 返回 `&nums[3]` |
| `element(nums, 3)[0]`、`0[element(nums, 3)]` | 40 | 返回的指针可以再当下标 |
| `by_offset` 和 `element` | 地址相同 | `p + i` 和 `&p[i]` |
| `maybe(nums, -1)` | `NULL` | 先判断再 `*` |
| `*maybe(nums, 1)` | 20 | |
| `*held()` 再 `*held() = 8` | 7，然后 8 | `box` 是 `static` |
| `**slot_of(slot, 1)` | 20 | 返回的是 `slot[1]` 这格的地址 |
| `*where = &a` | `*slot[1]` 变成 10 | 改的是指针格子，`b` 仍是 20 |
| `(*one_row(grid, 1))[2]` | 6 | 返回类型是 `int (*)[3]` |
| `choose(0)(20, 3)`、`(*choose(1))(20, 3)` | 23、17 | 返回的是函数指针 |
| `*element(nums, 3) = 99` | `nums[3]` 变成 99 | 返回的地址还能写 |

## 21 字符数组

`word[] = "abc"` 含 `'\0'`，`sizeof` 是 4，指针数到 `'\0'` 前是 3。`word[0]`、`0[word]`、`*(word + 0)` 都是 `a`。`&word[0]` 和 `word` 相同。

改字符：`A` → `Abc`，`p[1] = 'B'` → `ABc`，`*(p + 2) = 'Z'` → `ABZ`。逐个打出 `A B Z`。

`char big[8] = "abc"` 的 `sizeof` 是 8，内容仍是 `abc`。`q = big + 1` 打出 `bc`。花括号初始化要自己放 `'\0'`。

| `int *a` | 8 | `a[4]` 是 50 |
| `int (*block)[5]`，实参 `&nums` | `*block` 是 20 | `(*block)[2]` 是 30 |
| `int g[][3]` | 行指针 8，一行 12 | `g[1][2]` 是 6 |

## 24 二级指针

`nums` 是 `{10, 20, 30}`，`cursor` 开始指向 10。`pp` 是 `&cursor`。

| 写法 | 结果 | 记 |
|---|---|---|
| `**pp` | 10 | 两层才到 `int` |
| `*pp == cursor` | 相同 | 一层是指针格子 |
| `hop(&cursor)` | `*cursor` 变成 20 | `*pp = (*pp) + 1` |
| `read_two` | 20 | |
| `aim(&cursor, &nums[2])` | 30 | 把 `cursor` 改去指别的元素 |
| `local_step` | 函数里「动了」，`*cursor` 仍是 30 | 形参 `+ 1` |
| `write_int(&cursor, 7)` | `nums[2]` 是 7 | `**pp = 7` |
| `swap(&pa, &pb)` | `*pa` 是 2，`*pb` 是 1 | 交换的是两个指针格子 |
| `clear` 再 `aim` 回 `nums[0]` | 先是 `NULL`，再读到 10 | 空的时候不要 `*` |

## 25 结构体的二级指针

`*seat` 是调用者的那个 `struct Student *`。`(*seat)->name` 和 `(**seat).name` 是同一条路。

| 写法 | 结果 |
|---|---|
| `appoint(&monitor, &cls[1])` | bob，id 2 |
| `set_id(&monitor, 8)` | `monitor->id` 和 `cls[1].id` 都是 8 |
| `appoint` 到 `cls[0]` | ann |
| `local_step` | 函数里「动了」，`main` 里仍是 ann |
| `clear` | `monitor == NULL` |
| 先 `push` ann，再 `push` bob | 沿 `next` 打出 bob，然后 ann |

`push` 把新节点放在链的前面：`node->next = *head`，然后 `*head = node`。
