# 值传递和引用传递

C 的函数参数永远是值传递：调用时把格子里的内容抄进形参，函数结束形参就没了。教材里说的引用传递，在这些章节里是再传一层地址。形参里仍是地址的副本，`*` 顺着这个地址写回调用者那一格。

对应源文件：`02`、`03`、`04` 是 `int`，`17`、`18` 是结构体，`23` 是数组，`24`、`25` 是要改掉调用者的指针本身。

## 先分清两格

```text
值传递
main    a [ 10 ]
函数    x [ 10 ]  →  写成 100
        a 仍是 10。x 是另一格，返回后消失。

引用传递（传地址）
main    a [ 10 → 100 ]
函数    p [ &a ]
        *p = 100 写的是 a。p 这格仍是副本，返回后消失。
```

问一句就够：赋值号左边是形参自己，还是 `*`、`->` 后面的那格？

| 左边 | 改到哪里 | 章节 |
|---|---|---|
| `x = 100` | 只改形参里的数 | 02 |
| `p = NULL`、`p = p + 1` | 只改形参里的指针 | 02、04 |
| `*p = ...`、`s->id = ...` | 改调用者的对象 | 03、04、18 |
| `*pp = ...`、`*seat = ...` | 改调用者的指针变量 | 04、24、25 |
| `**pp = ...` | 改那个指针最终指着的对象 | 04、24 |

## 值传递

`02_pass_value.c` 里 `set_copy(a)`：`a` 是 10，形参 `x` 得到 10 的副本，`x = 100` 只改副本。函数里打出 100，`main` 里的 `a` 仍是 10。

```c
static void set_copy(int x)
{
    x = 100;
}
```

下面三次传进去的都是数，不是变量本身：

```text
set_copy(a)          抄的是 10
set_copy(*cursor)    先读出 10，再抄这个数
set_copy(nums[2])    抄的是 30
```

`drop(cursor)` 和 `step(cursor)` 看起来传了指针，改的仍是形参那一格：

```text
cursor [ &a ]              main 里不变
drop 的 p [ &a → NULL ]    只把副本清掉
step 的 p [ &a → 下一格 ]  只让副本往前挪
```

函数里可以印出「是」或「动了」。返回后 `cursor` 仍指向 `a`，`*cursor` 仍是 10。`income` 也是这次调用里的局部指针，和 `p` 一起结束。

结构体按值传递是整块复制，见 `17_struct_pass_value.c`。`change(stu)` 里 `s.id = 9`、`s.name[0] = 'Z'` 留在副本上，原来的学生仍是 `1 ann`。

块里如果有指针成员，复制的是地址数字：

```text
mark [ 60 → 100 ]  地址 0x5000

stu.score  [ 0x5000 ]
s.score    [ 0x5000 ]     副本里的地址和外面相同
*s.score = 100            顺着 0x5000 写到 mark
s.score = NULL            只清副本里这 8 字节
stu.score 仍是 0x5000
```

所以值传递不一定让所有外面的数都不变。不变的是被复制的那一块。块里面若抄来一个地址，`*` 仍能写到地址那头的对象。

`renamed` 改的也是副本，再用 `return` 交回另一份。调用者要有格子接住。原来的 `stu` 不会因为返回值而改变。

## 引用传递

`03_pass_address.c` 的形参类型是 `int *`。实参传 `&a` 或一个已经指向 `a` 的指针。形参 `p` 里是地址的副本，和 `main` 指向同一块 `int`。

```c
static void set_target(int *p)
{
    *p = 100;
}
```

`a` 从 10 变成 100。`add_one(p)` 再沿着同一地址加 1，变成 101。`set_target(&nums[2])` 只写第 2 格，旁边的 `nums[0]` 不动。

`swap(&a, &b)` 对调的是两格里的数。`a`、`b` 这两个变量还在原来的位置。

结构体同样，见 `18_struct_pass_address.c`：

```c
static void change(struct Student *s)
{
    s->id = 9;
    (*s).name[0] = 'Z';
}
```

`s->id` 就是 `(*s).id`，都写进原来那 12 字节。传 `&stu`，或传已经等于 `&stu` 的 `sp`，进函数的都是同一个地址。`swap_stu` 通过两个地址把两块学生的内容对调。`s[i]` 从这块再跨过 `i` 个学生，改的是数组里那一块，不是副本。

## 指针参数仍然是值传递

这是最容易混的一层，在 `04_pointer_copy.c`。

传 `cursor` 时，抄的是 `cursor` 里的地址。于是：

```text
*p = 100     能改 nums 里的 int       这是引用那一层对象
p = NULL     不能改 cursor 这格       指针变量本身仍是值传递
```

要改 `cursor` 这 8 字节，再取一次地址，形参做成 `int **`：

```text
pp [ &cursor ] ──► cursor [ &nums[0] ] ──► nums [ 100 ][ 20 ][ 30 ]

*pp = (*pp) + 1
一层 * 写的是 cursor。cursor 改去指 nums[1]，*cursor 变成 20。

**pp = 7
两层 * 写的是 cursor 当前那格，nums[1] 变成 7。cursor 的指向不变。
```

`24_second_level.c` 是同一套：`*pp` 就是 `cursor`，`**pp` 就是 `*cursor`。`local_step` 里 `pp = pp + 1` 只挪形参，`cursor` 不动。

`25_struct_second_level.c` 把对象换成学生：

```text
*seat = who         改 monitor 这格，让它指着另一个学生
(*seat)->id = n     改 monitor 当前指着的那块学生
seat = seat + 1     只改形参
```

`push` 能把头插进链表，是因为 `*head = node` 写的是调用者的头指针，不是形参自己。

## 数组看起来像引用

`23_array_param.c` 里这三种形参是同一种东西：

```c
void f(int a[5]);
void f(int a[]);
void f(int *a);
```

`nums` 传进去时退化成 `&nums[0]`。函数里的格子只有 8 字节，`sizeof` 是 8。`main` 里 `sizeof nums` 仍是 20，那 20 字节没有被复制。

所以 `a[0] = 99` 写回 `main` 的 `nums[0]`，效果和传地址一样。形参 `a = ...` 仍然只改函数里的指针副本。

要让形参表示整段数组，写成 `int (*block)[5]`，实参传 `&nums`。`sizeof *block` 才是 20。写 `(*block)[i]` 同样写到原来那 20 字节。

二维形参 `int g[][3]` 是指向一行的指针。`g[1][2]` 先跨过一行 12 字节，再写进原来的 `grid`。

## 对照

| | 值传递 | 引用传递（传地址） |
|---|---|---|
| 形参里是什么 | 对象的副本 | 对象地址的副本 |
| `int` | `void f(int x)` | `void f(int *p)`，调用写 `f(&a)` |
| 结构体 | `void f(struct Student s)` | `void f(struct Student *s)`，调用写 `f(&stu)` |
| 改形参自己 | 外面不变 | 外面的指针变量也不变 |
| 改 `*` 或 `->` | 值传递没有这条路，除非副本里还藏着指针 | 外面的对象改变 |
| 改调用者的指针变量 | 做不到 | 再加一层，`int **` 或 `struct Student **`，调用写 `&cursor`、`&monitor` |
| 数组 | 不会把整段复制进形参 | 传的就是首元素地址，`a[i] =` 改原来的数组 |
| 函数结束 | 形参格子消失 | 形参格子消失，被 `*` 写过的对象还在 |

记这一句：C 每次调用都在复制。复制的是数，改副本不影响原件。复制的是地址，`*` 会影响原件。想改指针变量自己，复制的必须是这个指针变量的地址。
