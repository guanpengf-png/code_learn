# 指针等价式

每条链都是同一格，或同一次调用里可以互相改写的式子。地址相同但类型不同的，写在链下面。字节数沿用这台 64 位机器：`int` 4，指针 8。

总规则：

```text
a[b]  =  *(a + b)  =  *(b + a)  =  b[a]
&*x   =  x                         x 是指针，且指着真实对象
*&y   =  y                         y 是对象
p + 1 的步长 = sizeof(*p)
```

`p + i` 算出新地址，不改 `p`。`p = p + 1` 才改 `p` 这格。

## 01 一级指针

`p` 里放着 `&a` 时：

```text
*p  =  a
p   =  &a  =  &*p
*&a =  a
```

`q = p` 之后两个格子里是同一个地址：

```text
*q  =  *p  =  a
```

`via = *&p` 时，`&p` 的类型是 `int **`，走回去仍是 `p` 里的地址：

```text
*&p  =  p
*via =  *p
```

`const` 不制造新的等价式。`const int *cp` 能改成另一个地址；`int *const fp` 这格一直等于 `&a`，`*fp` 仍等于 `a`。

## 02 传值

形参是新格子，和外面不是同一格。

```text
set_copy(a)         里的 x     ≠  a
set_copy(*cursor)   里的 x     =  调用前读出的那个数的副本
set_copy(nums[2])   里的 x     =  30 的副本
drop(cursor)        里的 p     =  cursor 当时那个地址的副本
step 里的 income    =  刚进来时的 p
```

函数返回后 `x`、`p`、`income` 都结束。`cursor` 仍是 `&a`，所以 `*cursor` 仍是 `a`。

## 03 传地址

形参里的地址和实参相同，`*` 碰到的是原来那格。

```text
set_target(&a)  里的 *p   =  a
add_one(p)      里的 *p   =  a          此时 main 的 p 已经是 &a
set_target(&nums[2]) 里的 *p  =  nums[2]
```

交换只换格子里的数：

```text
swap 之后  a 里的数 = 原来 b 里的数
           b 里的数 = 原来 a 里的数
```

连续写入：

```text
p[i]  =  *(p + i)
fill(nums, ...)     里的 p[0]  =  nums[0]
fill(&nums[0], ...) 里的 p[0]  =  nums[0]
```

`nums` 用在实参里时：

```text
nums  =  &nums[0]          类型都看成 int *
```

## 04 一层星和两层星

`cursor` 指向 `nums` 的某一格，`pp` 是 `&cursor` 时：

```text
*p    =  *cursor           p 是 int *，抄的是 cursor 里的地址
*pp   =  cursor            一层，碰到指针格子
**pp  =  *cursor           两层，碰到 int
*pp + 1  =  (*pp) + 1      先取出指针，再按 int 跨一格
```

所以：

```text
p = NULL          只改形参，cursor 不变
p = p + 1         只改形参，cursor 不变
*p = 100          nums[cursor 当前下标] = 100
*pp = *pp + 1     cursor 改去指下一格
**pp = 7          cursor 当前那格 = 7
```

`step` 里 `income = p` 只在这次调用内成立：`income` 是进来时的地址，`p + 1` 之后 `p ≠ income`。

## 05 下标

`p = nums`，`i = 2`，`at = nums + 2`。下面全部等于 `nums[2]`，也就是 30：

```text
nums[i]
= *(nums + i)
= *(i + nums)
= i[nums]
= p[i]
= *(p + i)
= *(i + p)
= i[p]
= (&nums[0])[i]
= *(&nums[i])
```

`at` 已经站在 `nums[2]` 上：

```text
at[0]   =  *at      =  nums[2]
at[-1]  =  *(at - 1) =  nums[1]
at[1]   =  *(at + 1) =  nums[3]
```

## 06 元素地址

`p = nums`，`i = 2`。下面是同一个地址：

```text
&nums[i]
= nums + i
= &i[nums]
= &*(nums + i)
= &p[i]
= p + i
= &nums[0] + i
```

再读回来：

```text
*(&nums[i])  =  nums[i]
*(&nums[0] + i)  =  nums[i]
```

表达式里的数组名：

```text
nums  =  &nums[0]          都是 int *，指向第一个 int
```

起始字节相同、类型不同：

```text
(void *)&nums  =  (void *)&nums[0]     同一个起始字节
&nums          的类型是 int (*)[5]      +1 跨 20 字节
&nums[0]       的类型是 int *           +1 跨 4 字节
sizeof nums    =  20                    对象本身
sizeof &nums   =  sizeof &nums[0]  =  8 指针格子
```

## 07 普通指针一步

`p = nums`，`end = nums + 5`：

```text
*(p + 1)  =  nums[1]  =  *(&nums[1])
p + 1     =  &nums[1]
*(p + i)  =  nums[i]  =  p[i]
sizeof *p =  sizeof(int)  =  4
end - nums  =  5           元素个数，不是字节
*walk++   =  *(walk++)     先读当前 int，再让 walk 前进
```

`*(p + 1)` 不改 `p`。`saved = p` 之后若 `p = p + 1`，则 `*saved = nums[0]`，`*p = nums[1]`。

## 08 数组指针一步

`block` 的类型是 `int (*)[5]`，开始指向 `table` 的第 0 行。`one = table[0]`，类型是 `int *`。

```text
*(block + 1)     =  block[1]          第 1 行
(*block)[c]      =  table[0][c]
(*(block + 1))[c] =  table[1][c]
block[1][1]      =  (*(block + 1))[1]  =  table[1][1]
*(one + 1)       =  table[0][1]
*(one + 4)       =  table[0][4]
```

步长：

```text
sizeof *one    =  4     int *
sizeof *block  =  20    一整行
sizeof table   =  40    两行
```

`block = block + 1` 之后，`(*block)[0] = table[1][0]`。`one` 仍指向 `table[0][0]`。

## 09 指针数组

`slot[i]` 里是一个 `int *`。`p = slot`，`block = &slot`。下面都读到 `slot` 第 `i` 个指针指着的那个 `int`：

```text
*slot[i]
= *i[slot]
= **(slot + i)
= **(&slot[i])
= slot[i][0]
= *(slot[i] + 0)
= **(p + i)
= *(*block)[i]
```

拆开第 `i` 格：

```text
slot + i     类型 int **，指向第 i 个指针格子
*(slot + i)  =  slot[i]     那个 int *
**(slot + i) =  *slot[i]    那个 int
&slot[i]     =  slot + i
```

`*(*p++)` 这一次调用里等于 `**(p++)`：先用当前格子，再让 `p` 前进。前进之后 `p` 不再等于 `slot`。

不要和下面这条写成同一个式子：

```text
*slot          =  slot[0]     已经是 &a，类型 int *
*slot + i      按 int 从 a 旁边挪
*(*slot + i)   ≠  *slot[i]    i ≠ 0 时到不了 b、c
```

`block + 1` 跨过整段 3 个指针，24 字节。`p + 1` 跨过一个指针，8 字节。

## 10 数组指针取值

`block = &nums`，`p = nums`，下标 2：

```text
(*block)[2]
= block[0][2]
= *(*block + 2)
= *(block[0] + 2)
= 2[*block]
= 2[block[0]]
= *&(*block)[2]
= p[2]
= nums[2]
= at2(&nums)
```

其中：

```text
block[0]  =  *block
*block    在 + 和 [] 里退化成 int *，和 p 从同一字节出发
sizeof *block  =  sizeof nums  =  20
sizeof p       =  8
```

## 11 二维数组

`grid[r][c]` 的整条链：

```text
grid[r][c]
= r[grid][c]
= c[grid[r]]
= c[r[grid]]
= *(*(grid + r) + c)
= (*(grid + r))[c]
= *(grid[r] + c)
= *(&grid[r][0] + c)
= *(*grid + r * 3 + c)
= row[r][c]
= *(flat + r * 3 + c)
= (*block)[r][c]
= block[0][r][c]
```

中间几步的类型：

```text
grid + r          类型 int (*)[3]，跨过 r 行，一行 12 字节
*(grid + r)       第 r 行，再退化成 int *
grid[r]           =  *(grid + r)
&grid[r][0]       =  退化后的 grid[r]
*grid             先落到第 0 行，再退化成 int *
*grid + r * 3 + c 按 int 从第一个字节线性数
flat              =  &grid[0][0]，和 *grid 退化后同一条路
block[0]          =  *block，整张表
```

`(*row)[c]` 然后 `row++`：读的是当前行，`row++` 之后 `row` 指向下一行。`*flat++ = *(flat++)`，按 `int` 连读 6 个。

三种 `+ 1`：

```text
flat + 1     4 字节
grid + 1     12 字节
block + 1    24 字节
```

## 12 指针函数

`element` 和 `by_offset` 交回同一个地址：

```text
element(p, index)   =  &p[index]
by_offset(p, index) =  p + index
*element(p, index)  =  p[index]
element(p, index)[0] =  *element(p, index)
0[element(p, index)] =  element(p, index)[0]
```

`slot_of(slot, index)` 交回的是指针格子的地址：

```text
slot_of(slot, i)  =  &slot[i]
*slot_of(slot, i) =  slot[i]
**slot_of(slot, i) = *slot[i]
```

`*where = &a` 等价于 `slot[1] = &a`，因为 `where` 就是 `&slot[1]`。

行指针和函数指针：

```text
one_row(grid, r)        =  &grid[r]          类型 int (*)[3]
(*one_row(grid, 1))[2]  =  grid[1][2]
choose(0)               =  add
choose(1)               =  sub
choose(0)(20, 3)        =  add(20, 3)
(*choose(1))(20, 3)     =  sub(20, 3)
picked = choose(0) 之后  picked(20, 3) = add(20, 3)
```

`*held()` 每次都是同一块 `static box`。`maybe` 在下标小于 0 时没有对象，不能写成 `*maybe(...)`。

## 13 函数指针怎么调用

`op` 里是 `add` 时：

```text
op(20, 3)
= (*op)(20, 3)
= (**op)(20, 3)
= add(20, 3)
= (&add)(20, 3)
```

函数名在表达式里变成入口地址：

```text
add  =  &add
```

`op = &sub` 之后，上面的链换成 `sub(20, 3)`。

指针函数那几条和 12 相同：

```text
*element(nums, 3)
= element(nums, 3)[0]
= 0[element(nums, 3)]
= *back(nums, 3)
= *(*back)(nums, 3)
= *backs[0](nums, 3)
```

`() ` 比 `*` 紧，所以：

```text
*back(nums, 3)   =  *(back(nums, 3))
*(*back)(nums, 3) =  *((*back)(nums, 3))
```

返回函数指针：

```text
choose(0)(20, 3)     =  add(20, 3)
(*choose(1))(20, 3)  =  sub(20, 3)
chooser(0)(20, 3)    =  choose(0)(20, 3)
(*chooser)(1)(20, 3) =  choose(1)(20, 3)
picked = choose(0) 之后 picked(20, 3) = add(20, 3)
```

函数指针数组，`ops[0]` 是 `add`、`ops[1]` 是 `sub` 时：

```text
ops[0](20, 3)
= (*ops[0])(20, 3)
= 0[ops](20, 3)
= (*(ops + 0))(20, 3)
= add(20, 3)

ops[1](20, 3)
= (*ops[1])(20, 3)
= (*bundle)[1](20, 3)
= sub(20, 3)
```

`named` 的类型就是 `int (*)(int, int)`，`named = sub` 时 `named(20, 3) = sub(20, 3)`。

## 14 函数指针参数

参数里的调用：

```text
fn(x)   =  (*fn)(x)
inc     =  &inc          作为实参时是同一个入口
dec     =  &dec
add     =  &add
sub     =  &sub
```

`apply` 这一句：

```text
*p = fn(*p)    等价于先算出 fn(原来的 *p)，再写回 p 指着的那格
```

`op` 里已经是 `inc` 时，`apply(&n, op)` 和 `apply(&n, inc)` 抄进 `fn` 的是同一个入口。`keep_if_null(x, NULL)` 没有函数可调用，结果就是 `x`。

## 15 函数指针数组

`ops[0]` 是 `add`、`ops[1]` 是 `sub` 时，`add(8, 2)` 是 10，`sub(8, 2)` 是 6：

```text
ops[i]
= i[ops]
= *(ops + i)

ops[i](8, 2)
= (*ops[i])(8, 2)
= (*(ops + i))(8, 2)
= (*bundle)[i](8, 2)
```

`bundle = &ops`，所以 `*bundle` 就是整段 `ops`。`cursor = ops` 时，`(*cursor++)(8, 2)` 等于先调用 `*(cursor)`，再让 `cursor` 指向下一格。

`named` 和 `ops` 是同一类数组，但不是同一块内存。`ops[0] = sub` 之后只有 `ops[0](8, 2) = sub(8, 2)`，`named[0]` 仍是 `add`。

## 16 结构体指针

`sp = &stu` 时：

```text
sp->id      =  (*sp).id      =  (&stu)->id  =  sp[0].id  =  stu.id
sp->name    =  (*sp).name    =  stu.name
&sp->id     =  &((*sp).id)   =  &stu.id
sp->name    用在表达式里  =  &stu.name[0]     类型 char *
```

`q = sp` 之后 `q->id = sp->id = stu.id`。写 `q->id` 就是写 `stu.id`。

## 17 结构体传值

`s` 是 `stu` 的副本，不是同一块：

```text
s.id     ≠  调用之后的 stu.id      改的是副本
s.name   ≠  调用之后的 stu.name
s.score  =  stu.score              复制发生时，两格里的地址数字相同
*s.score =  *stu.score = mark      顺着那个地址写到同一个 int
```

函数里再写 `s.score = NULL`，只改副本，返回后 `stu.score` 仍是 `&mark`。

`renamed` 的返回值是另一份副本。接住它的 `copy` 和 `stu` 不是同一块；`copy.score` 和 `stu.score` 里的地址仍相同。

## 18 结构体传地址

`s = &stu` 时：

```text
s->id        =  (*s).id        =  stu.id
s->name[0]   =  (*s).name[0]   =  stu.name[0]
```

`sp` 已经是 `&stu` 时，`set_id(sp, id)` 里的 `s->id = stu.id`。

数组：

```text
s[i]      =  *(s + i)
s[i].id   =  (s + i)->id
rewrite(cls, 1, ...) 里的 s[1]  =  cls[1]
```

`swap_stu` 之后，`stu` 那一块的内容等于交换前 `mate` 的内容，反过来也一样。

## 19 结构体走一步

`p = cls` 时：

```text
(p + 1)->name   =  p[1].name   =  (*(p + 1)).name   =  cls[1].name
(p + 1)->id     =  p[1].id     =  cls[1].id
p[i].name       =  (p + i)->name
sizeof *p       =  sizeof(struct Student)  =  12
end - cls       =  3           学生个数
```

`saved = p` 然后 `p = p + 1`：`saved` 仍是 `cls[0]`，`p` 是 `cls[1]`。

## 20 一组当成一个

`all` 开始指向 `room` 的第 0 组，类型是 `struct Student (*)[3]`：

```text
*(all + 1)            =  all[1]
(*all)[i].name        =  room[0][i].name
(*(all + 1))[i].name  =  room[1][i].name
all[1][2].name        =  room[1][2].name
(*all + 2)->name      =  room[0][2].name
(all[1] + 1)->name    =  room[1][1].name
```

`*all` 在 `+` 里退化成 `struct Student *`，所以 `*all + 2` 是第 0 组里的第三个学生。`all + 1` 先跨过一整组。

```text
sizeof room[0][0]  =  12
sizeof *all        =  36
```

`all = all + 1` 之后，`(*all)[0] = room[1][0]`。

## 21 字符数组

`word` 是数组时：

```text
word[0]      =  0[word]      =  *(word + 0)
&word[0]     =  word         表达式里退化成 char *
*(word + i)  =  word[i]
p = word 之后  p[i] = word[i]，*(p + i) = word[i]
```

`sizeof word` 是数组自己的字节，含结尾的 `'\0'`。`char word[] = "abc"` 时是 4。`char big[8] = "abc"` 时 `sizeof big` 是 8，内容和 `word` 一样以 `'\0'` 结束。`q = big + 1` 之后，`q` 指向 `big[1]`，`big` 的第 0 格还在。

## 22 字符指针

```text
*(text + 0)  =  text[0]
text + 1     指向同一串的下一个字符
sp[0]        =  *sp           =  rows[0]
*(sp + 1)    =  sp[1]         =  rows[1]
*walk++      =  *(walk++)     先取出当前这串的地址，再让 walk 前进
```

`writable = word` 时 `writable[0] = word[0]`。`fixed = word` 且不再改 `fixed` 时 `fixed = &word[0]`。`view = view + 1` 之后 `view` 指向 `word[1]`。

`sizeof text` 是指针格子 8。`sizeof word` 是数组 4。这两个 `sizeof` 不能写成相等。

## 23 数组形参

三种写法在函数里是同一种指针：

```text
void f(int a[5])
void f(int a[])
void f(int *a)
```

此时：

```text
a        =  &nums[0]       类型 int *
a[i]     =  nums[i]
sizeof a =  sizeof(int *) =  8
sizeof nums              =  20       只在 main 里成立
```

整段传进来时：

```text
void g(int (*block)[5])     实参是 &nums
(*block)[i]  =  nums[i]
sizeof *block =  sizeof nums =  20
```

二维形参 `int g[][3]`：

```text
g          类型 int (*)[3]
g[1]       =  *(g + 1)
g[1][2]    =  (*(g + 1))[2]
sizeof g 的指针格子 =  8
sizeof g[0]        =  12
```

## 24 二级指针

`pp = &cursor` 时：

```text
*pp   =  cursor
**pp  =  *cursor
*pp + 1  =  (*pp) + 1  =  cursor + 1     按 cursor 指着的类型跨
```

因此：

```text
*pp = *pp + 1     等价于  cursor = cursor + 1
*pp = target      等价于  cursor = target
**pp = value      等价于  *cursor = value
*pp = NULL        等价于  cursor = NULL
```

`local_step` 里的 `pp = pp + 1` 只改形参，和 `cursor = cursor + 1` 不是同一个式子。

`swap(&pa, &pb)` 交换的是两个指针格子里的地址：

```text
交换后 *pa = 原来 *pb 指着的对象
      *pb = 原来 *pa 指着的对象
```

`a`、`b` 那两个 `int` 格子还在原处。

## 25 结构体二级指针

`seat = &monitor`，且 `monitor` 已经指向某个学生时：

```text
*seat            =  monitor
(*seat)->name    =  monitor->name
(*seat)->id      =  monitor->id
(**seat).name    =  (*seat)->name
(**seat).id      =  (*seat)->id
```

所以：

```text
*seat = who       等价于  monitor = who
(*seat)->id = n   等价于  monitor->id = n
*seat = NULL      等价于  monitor = NULL
```

`local_step` 里 `seat = seat + 1` 只改形参，`monitor` 不变。

`push` 的两步：

```text
node->next  =  *head
*head       =  node
```

第二次 `push` 时，`*head` 已经是上一个节点，所以新节点的 `next` 指向它，头改成新节点。沿着 `next` 先走到后推进去的那个学生。
