# Shadow Dance 需求文档

终端里的音游。音符沿车道下落，到达判定线时按对应的键。规则对齐原来的 Java 版，画面改成字符。

坐标仍用 Java 窗口：宽 1024，高 768，判定线在 y = 657。一帧约 16.7 毫秒（60 帧/秒）。

编译和检查：

```
make
./shadow_dance
make test
```

`shadow_dance`、`shadow_dance.dSYM`、`shadow_dance_asan.dSYM` 是编译产物。`.dSYM` 里是调试符号，不参与玩法，也不对应下面任何一条需求。

## 需求一览

| 编号 | 需求 | 完成位置 |
|---|---|---|
| R1 | 选关、开局、结束、返回选关 | `main.c`：`game_start`、`game_clear`、`draw_menu`、`draw_end`、`main` |
| R2 | 从 CSV 读出车道和音符 | `lane.c`：`lanes_load`；谱面在 `res/` |
| R3 | 三种音符：普通、长按、特殊 | `note.c`：`note_create` 和三张函数表 |
| R4 | 音符按帧下落，未出场的先不动 | `note.c`：`note_visible`、`note_move`；`main.c`：`advance_notes` |
| R5 | 按键只打该车道最早、已经出场的音符 | `main.c`：`handle_key`、`key_lane`、`find_lane` |
| R6 | 按距离给 PERFECT / GOOD / BAD / MISS | `note.c`：`score_from_distance`；`game.h` 里的分数 |
| R7 | 掉出窗口扣分；特殊音符不扣 | `main.c`：`advance_notes`；`note.c`：`note_out_of_window` |
| R8 | 分数、提示、通关线 | `score.c` 全部函数 |
| R9 | 四种特殊效果：加速、减速、双倍分、清轨 | `note.c`：`special_activated` |
| R10 | 第 3 关：敌人、守卫、射箭 | `enemy.c` 全部函数；`main.c`：`update_level3` |
| R11 | 画面、键盘、帧率 | `main.c`：`input_poll`、`draw_play`、`sleep_frame`、`enter_raw` |
| R12 | 上述规则有自动检查 | `main.c`：`run_tests`；`make test` |

## R1 选关和流程

`main` 里的循环按三个状态走。

1. 还没开始：`draw_menu` 画出选关。按 `1` / `2` / `3` 时 `game_start` 读对应谱面。
2. 正在玩：`update_play` 每帧更新，`draw_play` 画画面。
3. 全部音符处理完：`finished` 变成 1，`draw_end` 显示结果。空格调用 `game_clear`，回到选关。

默认谱面和通关分：

| 按键 | 谱面 | 通关分 | 内容 |
|---|---|---|---|
| 1 | `res/test1.csv` | 150 | 四条方向轨，普通音符和长按 |
| 2 | `res/test2.csv` | 400 | 四条方向轨 |
| 3 | `res/test3.csv` | 350 | 左右轨加特殊轨，并开启敌人 |

完整长谱在 `res/level1.csv`、`level2.csv`、`level3.csv`，当前选关不读它们。`Q` 或 `Esc` 退出。打不开谱面时，菜单上显示 `打不开 res/testN.csv`，留在选关。

## R2 谱面

`lanes_load` 读 CSV。空行和凑不齐三列的行跳过。某一行是车道或音符，但内容非法，整份谱面作废并释放已读内容。

两种行：

```
Lane,方向,横坐标
方向,音符种类,出场帧
```

方向是 `Left` `Right` `Up` `Down` `Special`，大小写不限。车道横坐标来自文件，纵坐标固定 384（`LANE_Y`）。最多 8 条车道。

音符种类是 `Normal` `Hold` `DoubleScore` `SpeedUp` `SlowDown` `Bomb`。读完后每条车道按出场帧从小到大排序。文件里的第一条音符会保留。

音符列表存的是 `Note *`。加速和双倍分要改到车道上那一个音符，不能存一份副本。车道本身放在定长数组里，音符里的 `Lane *` 不会因为扩容失效。

## R3 音符种类

`note_create` 按种类挂上函数表。`kind` 记录是哪一种，`vt` 里的函数指针决定距离、能否打中、分数、提示和生效时做什么。

| CSV 种类 | `kind` | 画面字符 | 起点 y | 高度 | 函数表 |
|---|---|---|---|---|---|
| Normal | `NOTE_NORMAL` | 车道符号 `< > ^ v` | 100 | 64 | `VT_NORMAL` |
| Hold | `NOTE_HOLD` | 身体是 `\|`，判定点用车道符号 | 24 | 229 | `VT_HOLD` |
| DoubleScore | `NOTE_SPECIAL` | `2` | 100 | 64 | `VT_SPECIAL` |
| SpeedUp | `NOTE_SPECIAL` | `+` | 100 | 64 | `VT_SPECIAL` |
| SlowDown | `NOTE_SPECIAL` | `-` | 100 | 64 | `VT_SPECIAL` |
| Bomb | `NOTE_SPECIAL` | `B` | 100 | 64 | `VT_SPECIAL` |

初速都是 2。未知种类返回空指针，读谱时整份失败。

## R4 下落

`note_visible`：当前帧小于 `start_frame` 时，这个音符还没出场，不移动，也不能打。

出场之后，`note_move` 每帧让 `y` 增加 `speed`。双倍分剩余帧数也在这一帧减 1。同一条车道按出场顺序处理，遇到还没出场的就停，后面的更晚。

`note_out_of_window`：音符中心减去半高之后仍大于 768，算掉出屏幕，从车道删掉。

## R5 按键判定

一帧只认一个方向，优先级是左、右、上、下、空格。

| 输入 | 车道 |
|---|---|
| 左方向键或 `A` | Left |
| 右方向键或 `D` | Right |
| 上方向键或 `W` | Up |
| 下方向键或 `S` | Down |
| 空格 | Special |

`handle_key` 只看这条车道列表里的第一个音符，而且它必须已经出场。

- 普通音符、特殊音符：打中后从车道删除。
- 长按：第一次打中只把 `pressed` 设为 1，音符还留在车道上。再按一次同一条轨道，判定尾部，然后删除。终端读不到松手，所以第二次按下当作松键。
- 炸弹：生效时自己把整条车道清空，调用方不再删除它。

长按的距离在 `hold_distance`。还没按下时，判定点在中心上方 82；按下之后，判定点改到中心下方 82。画面上的字符画在 `note_mark_y`，和这个判定点是同一个 y。

## R6 距离和分数

距离是判定点和 y = 657 的纵向绝对差。`game.h` 规定分数，`note.h` 规定距离。

| 距离 | 判定 | 分数 | 画面 |
|---|---|---|---|
| ≤ 15 | PERFECT | +10 | 绿底 |
| ≤ 50 | GOOD | +5 | 黄 |
| ≤ 100 | BAD | −1 | 紫 |
| ≤ 200 | MISS | −5 | 红 |
| > 200 | 按不中 | 不加分 | 车道原色 |

普通音符和长按用上面这张表，能否按下的上限是 200。

特殊音符能否按下的上限是 50。加速、减速各 +15 分，提示是 `Speed Up`、`Slow Down`。双倍分和炸弹本身是 0 分，提示是 `Double Score`、`Lane Clear`。

掉出窗口时，普通音符和长按固定 −5，提示 `MISS`。这一下不乘双倍分。特殊音符掉出去不扣分。

## R7 和 R8 计分与通关

`score_add` 把分数加进 `total`，并把提示留下来。`score_tick` 每帧把提示帧数减 1，减到 0 就不再画。提示停留 30 帧，大约半秒。

通关看结局画面：`total >= win_score` 显示 `CLEAR!`，否则显示 `TRY AGAIN`。分数可以是负数。

## R9 特殊效果

`special_activated` 先记分和提示，再改场上的音符。被改的是这一帧已经收集到的全部音符，包括还没出场的。

| 效果 | 作用 |
|---|---|
| SpeedUp | 每个音符 `speed` 加 1 |
| SlowDown | 每个 `speed > 1` 的音符减 1，最低保持 1 |
| DoubleScore | 每个音符的双倍分剩余帧设为 480。之后这些音符自己的判定分乘 2 |
| Bomb | 清空自己这条车道上的全部音符 |

双倍分乘的是判定分。速度音符的 +15 也会乘。掉出窗口的 −5 在 `advance_notes` 里直接调用 `score_add`，不经过这个乘法。

## R10 第 3 关

只有 `level == 3` 时 `update_level3` 才运行。守卫画成 `G`，固定在 (800, 600)。敌人画成 `E`，箭画成 `*`。

| 规则 | 函数 | 数值 |
|---|---|---|
| 每 600 帧尝试生成一个敌人 | `enemy_spawn` | 最多 64 个 |
| 出生范围 | `enemy_spawn` | x 在 100 到 900，y 在 100 到 500，两端都包含 |
| 左右移动，碰到边界回头 | `enemy_move` | 速度 1 |
| 离某个已出场音符的距离 ≤ 104，吃掉它 | `enemy_hits_note` | 不扣分，只删除 |
| 按 `F` 朝最近的敌人射一支箭 | `guardian_fire` | 没有敌人、或距离为 0、或箭已有 32 支，则不射 |
| 箭沿发射方向飞行 | `projectile_move` | 速度 6 |
| 箭飞出 1024×768 就消失 | `projectile_out` | |
| 箭离敌人 ≤ 62，敌人消失 | `projectile_hits` | 这一帧的这支箭还可以继续打别的敌人 |

## R11 画面和输入

`enter_raw` 把终端改成不回显、不等回车。程序退出、`Ctrl+C` 或 `SIGTERM` 时恢复终端。

`draw_play` 把 1024×768 映射到当前终端大小。横线是判定线，竖线是车道，车道底部的字符是判定点。音符靠近判定线时按 R6 的距离变色。顶行左边是 `SCORE 当前分 / 通关分`，右边是关卡号。

`sleep_frame` 把循环锁在大约 60 帧/秒。这一帧花的时间超过一帧，下一帧的计划时间改成现在，不再补帧。

## R12 自动检查

`./shadow_dance --test` 不进画面，检查这些结果：

- 距离、四档判定、200 以外按不中、掉出窗口的 y
- 长按头部和尾部的距离
- 加速改变尚未出场音符的速度，减速不低于 1
- 双倍分持续 480 帧，PERFECT 变成 20
- 炸弹清空整条车道
- `test1.csv` 4 条轨、18 个音符，第一条出场帧是 100
- `test2.csv` 28 个音符，`test3.csv` 21 个音符
- 没有敌人时不射箭；有敌人时箭朝目标飞
- 敌人贴上音符算命中，碰到左边界回头

通过时打印 `全部通过：谱面、判定、双倍分、变速、炸弹、射箭`。

## 每个文件负责什么

| 文件 | 完成的需求 |
|---|---|
| `game.h` | 窗口、判定线、车道种类、四档分数。R4、R6、R10 用这些常量 |
| `score.h` `score.c` | R8。加分、提示停留、是否达到通关分 |
| `note.h` `note.c` | R3、R4、R6、R9。创建音符、函数表、移动、距离和特殊效果 |
| `lane.h` `lane.c` | R2。读 CSV、按出场帧排序、从车道删除一个音符 |
| `enemy.h` `enemy.c` | R10。生成、移动、吃音符、射箭、命中 |
| `main.c` | R1、R5、R7、R11、R12。流程、按键、掉出扣分、第 3 关调度、画面 |
| `res/test1.csv` 到 `test3.csv` | R1 实际加载的三关 |
| `res/level1.csv` 到 `level3.csv` | 完整谱，当前选关不用 |
| `Makefile` | 编译 `shadow_dance`，`make test` 跑 R12 |

`main.c` 把各部分接在一帧里，顺序是：第 3 关的敌人和箭，然后按键，然后音符下落，最后看车道是否已经空了。
